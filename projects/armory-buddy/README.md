# Armory Buddy

**World of Warcraft player companion and addon initiative**

**Status:** Planned / in development. No installable addon, live service, or API-enabled build is published from this repository yet.

## Goal

Armory Buddy aims to give players useful next-step guidance based on their character and game version, rather than a giant unfiltered list of every possible item.

The product direction includes:
- Practical gearing guidance and where to earn upgrades
- Talents and progression information relevant to the player's build
- Profession leveling and crafting recommendations
- Questing and activity suggestions
- Compatibility-aware addon information and creator attribution
- Optional friend comparisons where technically supported and privacy-permitted

These are **planned capabilities**, not a list of shipped or verified features. Exact implementations depend on what World of Warcraft addons, authorized data sources, and services allow.

## Data sources and permissions

We intend to respect Blizzard's addon policies, CurseForge's terms, and mod authors' distribution permissions.

No CurseForge API approval is implied. API keys must stay off the client; we will not mirror CurseForge files or cache restricted API data without appropriate permission.
