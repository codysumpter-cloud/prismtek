# Contributing to Prismtek

Thanks for helping make game tools better for players and mod authors.

## Before you contribute

Please open an issue for a new project or a substantial change. This is a public umbrella repository, **not** a mirror of Prismtek's private website, infrastructure, or internal workspaces.

We welcome reproducible bug reports, useful design feedback, corrections, accessibility improvements, documentation, and proposed additions to independently released game tools.

## Pull request guidelines

1. Explain the user problem and what the change improves.
2. Keep changes focused; document how to test them.
3. Identify supported games, versions, and any external APIs or permissions required.
4. Confirm you authored the material or have verifiable rights to contribute it. Attribute and license any third-party dependencies/assets.
5. Include no private code, user data, keys, tokens, credentials, internal handoffs, deployment configuration, or unlicensed assets.
6. Include screenshots or recordings only if they contain no private information.
7. For public software, declare its **project-specific license** before distributing it.

**Important licensing note:** This umbrella repository is rights-reserved by default. If a project has no explicit license, discuss the licensing terms in an issue **before submitting code**. Submission is not a transfer of your copyright and does not automatically make your contribution open-source.

## Mod authors and game companies

We value author credit, original release pages, donation links, license notices, and distribution controls. Please do not submit third-party CurseForge files, game assets, scraped platform data, or other proprietary material without verified permissions and a clear source.

## Review and conduct

Be constructive. Maintainers can decline contributions for quality, safety, licensing, scope, or maintainability reasons. Read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

For security vulnerabilities, use [SECURITY.md](SECURITY.md) rather than a public issue.
